# Quick Start

- If you want to understand what data is in a downloaded package, and the steps and quality of how it was processed, see the `Pipeline WebLog` ({ref}`The Pipeline WebLog <sec-weblog>`).
- If you want to restore the calibrated MS, run `scriptForPI.py` ({ref}`Archived scripts <sec-allscripts>`) or `casa_piperestorescript.py` ({ref}`The Pipeline script to restore calibrated MSs <sec-piperestorescript>`) to restore calibrated MSs.
- If you want to see, edit, or rerun the pipeline task commands that were run, you want `casa_pipescript.py` ({ref}`The Pipeline processing script <sec-pipescriptintro>`).
- If you want to see the CASA task calls that were used, either look at the casa log linked at the bottom of each pipeline processing stage of the "By Task" section of the WebLog, or see the full `casa_commands.log` file ({ref}`CASA equivalent commands file <sec-casacommandslog>`).
- We appreciate you citing the ALMA pipeline in publications! Guidelines for what and how to cite are described {ref}`here <sec-acknowledgement>`.

# Viewer.js Vendor Assets

This directory contains pristine, unmodified third-party vendor assets from **Viewer.js**.

* **Package:** `viewerjs` (v1.11.7)
* **Author:** Chen Fengyuan (https://chenfengyuan.com)
* **Repository:** https://github.com/fengyuanchen/viewerjs
* **License:** [MIT License](https://github.com/fengyuanchen/viewerjs/blob/main/LICENSE)

## Files in this Directory

* `viewer.min.js`: Complete Viewer.js core and UI engine (UMD build, zero dependencies).
* `viewer.min.css`: Base stylesheet with toolbar styles and transforms.

## Integration

All project-specific initialization logic is in:
* `../viewer_init.js`: Auto-binding to Sphinx `<figure>` and `<img>` elements.

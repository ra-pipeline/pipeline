15 

16 Applies a sequence of heuristic flagging tests to the Tsys caltable. If a manual flagging

18 Tsys spectra per spw per antenna after all flagging has been applied. 

19 

20 The flagging tests, applied in order, are: 

21 

22 1. **nmedian** (``flag_nmedian``): flag Tsys spectra whose median value is more than 

23 ``fnm_limit`` (default 3.0) times the median of all spectra. 

24 2. **derivative** (``flag_derivative``): flag spectra with a high median derivative 

25 (``fd_max_limit``), targeting ``ringing`` spectra. 

26 3. **edgechans** (``flag_edgechans``): flag the edge channels of each spw 

27 (``fe_edge_limit``). 

28 4. **fieldshape** (``flag_fieldshape``): flag spectra whose shape differs significantly 

29 from the reference BANDPASS intent shape (``ff_max_limit``, ``ff_refintent``). 

30 5. **birdies** (``flag_birdies``): flag narrow spectral features (``fb_sharps_limit``). 

31 6. **toomany** (``flag_toomany``): flag all antennas in a timestamp/spw if the fraction 

32 already flagged exceeds ``tmf1_limit``; flag all timestamps in a spw if the fraction 

33 entirely flagged exceeds ``tmef1_limit``. 

34 

35 Examples: 

36 1. Flag Tsys measurements using all recommended tests: 

37 

38 >>> hsd_tsysflag() 

39 

40 2. Flag using all tests except ``fieldshape``:

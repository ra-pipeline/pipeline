11 """Performs temporal phase-up and derives bandpass calibration solutions. 

12 

13 This task self-calibrates the bandpass calibrator by first obtaining 

14 phase-only solutions on a short time interval determined by signal-to-noise. 

15 It then calculates the antenna-based bandpass phase and amplitude solutions 

16 using an SNR-dependent frequency interval. 

17 

18 Notes: 

19 **Temporal Phase-Up Workflow** 

20 

21 As of PL2025, the `solint` and `combine` options are computed to achieve the 

22 target `phaseupsnr`. If `solint` is not `'int'`, the `combine` parameter is 

23 set to `'scan,spw'` to combine data from all spectral windows, thereby 

24 improving SNR. In this case, a temporary `gaincal` solution is made to 

25 obtain per-spw phase-offsets to align the phases of all spws. The 

26 `solint` is then calculated based on the SNR for the aggregate bandwidth. 

27 

28 The logical workflow is illustrated below: 

29 

30 .. figure:: /figures/PL2025_hifa_bandpass_phaseup.png 

31 :width: 60% 

32 :alt: Workflow for hifa_bandpass temporal phase-up 

33 

34 The logical workflow for the temporal phase-up process used in the 

35 :func:`~pipeline.hifa.cli.hifa_bandpassflag` and :func:`~pipeline.hifa.cli.hifa_bandpass` tasks that compute the 

36 `gaincal` `solint` and `combine` parameters. 

37 

38 **Frequency Interval Calculation** 

39 

40 The frequency interval for the final bandpass solution is determined by 

41 SNR. Since PL2024, this interval is rounded to counteract the `floor()` 

42 function in CASA, ensuring the interval has the desired number of 

43 channels. If the interval needed to reach the required SNR results in 

44 fewer than 8 channels, the interval is set to one-eighth of the 

45 bandwidth, and the result is assigned a QA subscore of 0.70. 

46 

47 **WebLog Output and QA Metrics** 

48 

49 The WebLog for this stage includes plots of amplitude and phase vs. 

50 frequency for the reference and a typical antenna, with the atmospheric 

51 transmission curve overlaid. QA metrics are calculated as follows: 

52 

53 - **Amplitude SNR Metric**: An error function with a 1-sigma deviation 

54 of 1.0 for the amplitude signal-to-noise ratio. 

55 

56 - **Phase Derivative Deviation (DD) Metric**: An error function with a 

57 1-sigma deviation of 0.03 for the "outlier fraction" (fraction of 

58 channels with a phase change > 5 MAD). This is mapped to a linear 

59 score: 

60 

61 - 0.34 - 0.66 for DD < 0.2 (>12% outliers) 

62 - 0.67 - 0.9 for DD between 0.2 - 0.3 

63 - 0.91 - 1.0 for DD >= 0.3 (<8% outliers) 

64 

65 - A QA sub-score of 0.9 is assigned if spws were combined in the 

66 phase-up step (from PL2025). 

67 

68 **BLC FDM Subband QA (PL2025+)** 

69 

70 For data from FDM spectral windows using the Baseline Correlator (BLC), 

71 a new QA assesses anomalous features (e.g., offsets, jumps) at subband 

72 edges (effective width 58.59375 MHz). The score is based on five 

73 heuristics (two for phase, three for amplitude) per spw, antenna, and 

74 polarization that check for noisy subbands, offsets between subbands, 

75 and large amplitude spikes. 

76 

77 - If any heuristic is triggered, the QA score is between 0.35 and 0.65, 

78 based on the fraction of the affected spw. 

79 - The evaluation is skipped and a score of 0.70 is assigned if an spw 

80 is narrow (< 125 MHz) or if low SNR requires a frequency interval 

81 >= the subband width. 

82 - If no issues are found or the data is not BLC FDM, the score is 1.0. 

83 

84 Examples: 

85 1. Run with recommended settings: 

86 

87 >>> hifa_bandpass() 

88 

89 """

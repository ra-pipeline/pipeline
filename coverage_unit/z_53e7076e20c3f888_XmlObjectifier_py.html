57""" 

58This module is used to create native Python objects representing an XML document 

59rendering the elements into a hierarchical tree. Name spaces can optionally be 

60mapped into the element names by specifying 'mapNameSpaces = 1'. Leading 

61characters can be omitted in the name space mapping using the 'skipChars' 

62argument. 

63 

64Characters that are not allowed in Python names ('.', '-', '/', ':') are mapped 

65to '_'. 

66 

67The resulting Python object can be modified and serialized into XML again using 

68the 'writexml' method. 

69 

70Example usage: 

71 

72import XmlObjectifier 

73xmlObject = XmlObjectifier.XmlObject(xmlString = <XML string>, 

74 skipChars = <string>) 

75 

76or 

77 

78xmlObject = XmlObjectifier.XmlObject(fileName = '<file name>', 

79 skipChars = <string>)

85<TelCalResult xmlns="Alma/TelCalResult" 

86 xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" 

87 xsi:schemaLocation="Alma/TelCalResult/TelCalResult-single.xsd"> 

88 <TelCalResultEntity entityId="2718281828" entityIdEncrypted="" 

89 entityVersion="0.1"/> 

90 <TelCalResultRef entityId="2718281827"/> 

91 <SchedBlockRef entityId="31415926534"/> 

92 <TelCalResultDetail> 

93 <ResultKind>FocusOffset</ResultKind>

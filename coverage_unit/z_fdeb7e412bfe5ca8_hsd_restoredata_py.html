8 """Restore flagged and calibrated single-dish MeasurementSets from archived pipeline products. 

9 

10 Restores flagged and calibrated MeasurementSets from archived ASDMs and pipeline flagging and 

11 calibration data products. This task is called at the beginning of single-dish imaging-only 

12 pipeline recipes. 

13 

14 Assumes ASDMs are present in the directory given by ``rawdata_dir`` (default: ``'../rawdata'``). 

15 By default (``copytoraw=True``), the pipeline products are copied from ``products_dir`` 

16 (default: ``'../products'``) to ``rawdata_dir`` at the start of the task. If 

17 ``copytoraw=False``, the products are expected to already be in ``rawdata_dir``. 

18 

19 When converting an ASDM to MS, if the output MS already exists in the output directory, 

20 the ``importasdm`` step is skipped and the existing MS is imported instead. 

21 

22 The expected products per ASDM are: 

23 

24 - a compressed tar file of the final flag versions, e.g. 

25 ``uid___A002_X30a93d_X43e.ms.flagversions.tar.gz`` 

26 - a text file with applycal instructions, e.g. 

27 ``uid___A002_X30a93d_X43e.ms.calapply.txt`` 

28 - a compressed tar file with session caltables, e.g. 

29 ``uid___A001_X74_X29.session_3.caltables.tar.gz`` 

30 

31 The task performs the following operations: 

32 

33 1. Imports the ASDM(s) to MS. 

34 2. Removes the default MS.flagversions directory created by the filler. 

35 3. Restores the final MS.flagversions directory stored by the pipeline. 

36 4. Restores the final set of pipeline flags to the MS. 

37 5. Restores the final calibration state of the MS. 

38 6. Restores the final calibration tables for each MS. 

39 7. Applies the calibration tables to each MS. 

40 

41 Examples: 

42 1. Restore pipeline results for a single ASDM in a single session: 

43 

44 >>> hsd_restoredata(vis=['uid___A002_X30a93d_X43e'], session=['session_1'], ocorr_mode='ao') 

45 

46 """

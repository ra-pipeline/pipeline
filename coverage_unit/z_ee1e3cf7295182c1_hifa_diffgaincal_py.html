6def hifa_diffgaincal(vis=None, flagging_frac_limit=None, hm_spwmapmode=None, missing_scans_frac_limit=None): 

7 """Derive SpW phase offsets from differential gain calibrator. 

8 

9 This task creates the spectral window phase offset table used to allow 

10 calibrating the "on-source" spectral setup with phase gains from a 

11 "reference" spectral setup. Currently this setup with two different 

12 SpectralSpecs is used by the band-to-band mode, for a high and low 

13 frequency band. 

14 

15 A bright point source quasar, called the Differential Gain Calibrator 

16 (DIFFGAIN) source, is used for this purpose. This DIFFGAIN source is typically 

17 observed in groups of interleaved "reference" and "on-source" scans. These 

18 blocks typically occur once at the start and once at the end of the 

19 observation. In very long observations, there may be a group of scans 

20 occurring during the middle. 

21 

22 The task first performs a temporary phase solution on the low frequency 

23 "reference" data using ``solint='inf'``. Next, the "phase offset" solution 

24 using the high frequency "on-source" data is made with scan combination. 

25 Separately combining those scan encompassing the "start" and "end" DIFFGAIN 

26 blocks respectively. The "reference" gaintable is also pre-applied. Finally, 

27 temporary "residual" phase solutions are produced using the high frequency 

28 data with ``solint='inf'`` while both the "reference" and "phase offset" 

29 phase solutions are pre-applied. 

30 

31 The "residual" solutions are designed as to scatter about zero degrees phase 

32 with no drift, as shown in the figure below (right panel). The "residuals" 

33 not limited by SNR should ideally be within +/-30 deg; acceptable-conditions data 

34 should be within +/-50 deg. There should be no significant offset or outlier 

35 solutions from the base zero degree phase. QA sub-scores are described below. 

36 

37 For all solves ``refantmode='strict'`` is used, such that the reference  

38 antenna as established in :func:`~pipeline.hif.cli.hif_refant` cannot be swapped 

39 when data are flagged. If solutions are poor, one should investigate fixing 

40 the reference antenna. 

41

47 

48 **Plots in the weblog**: The first set (left) shows the diffgain phase correction to be applied to the 

49 target source (the band-to-band offset). A plot is shown for each spectral window, with phase correction data 

50 points plotted per antenna and correlation as a function of time. The second set (right) shows the DIFFGAIN phase 

51 residuals as a function of time. The residual phase solutions should scatter about zero with no drift or outliers. 

52 

53 As of PL2025, low-SNR heuristics allow ``combine='spw'`` to be used in any of the three solve steps. 

54 The gaincal workflow and low SNR logical flow are shown in the figure below. 

55 

56 .. figure:: /figures/PL2026_hifa_diffgaincal_incHeuristic_lowSNR.png 

57 :width: 60% 

58 :alt: Gain solution workflow for hifa_diffgaincal 

59 

60 Left: gain solution workflow with low-SNR heuristic before each ``gaincal``. 

61 Right: low-SNR heuristic logic for spectral window combination. 

62 

63 The heuristic is triggered if: 

64  

65 1. ``combine='spw'`` was triggered as required for the phase-up (in :func:`~pipeline.hifa.cli.hifa_spwphaseup` 

66 for the DIFFGAIN intent - using the relevant REF or the SRC). The previously computed SNR and ``solint`` 

67 are used to calculate whether spw combination is required for the scan based phase solves, or in the case 

68 of the band-to-band offset - the group of scans, as to meet an SNR of 5.0. If this SNR threshold is not met, 

69 spw combination is triggered. 

70 2. A temporary ``gaincal`` shows that (i) not all spw solutions are made; (ii) the fraction of flagged solutions 

71 exceeds 0.5 of the total solutions, and (iii) the fraction of missing scans exceeds 0.7 of the expected scans. 

72 

73 Notes: 

74 QA sub-scores: 

75 

76 - 1.0 if each caltable (reference, band-to-band offset, residual) is successfully produced; 

77 0.0 if any table is missing (which invalidates the calibration). 

78 - 0.9 (informative only) if ``combine='spw'`` was required for any of the three solve steps; 

79 1.0 otherwise. 

80 - Residual solution phase offsets, rms, outliers: 

81 - 1.0 if phase `parameter` is <30 deg 

82 - 0.9 if phase `parameter` is between 30-50 deg 

83 - 0.67 if phase `parameter` is between 50-70 deg 

84 - 0.66 if phase `parameter` >=70 deg 

85 

86 :func:`~pipeline.hifa.cli.hifa_diffgaincal` is only used in band-to-band (diffgain) recipes, but other  

87 required pipeline tasks are DIFFGAIN-aware and handle band-to-band data correctly. 

88 

89 Examples: 

90 1. Derive SpW phase offsets from differential gain calibrator. 

91 

92 >>> hifa_diffgaincal() 

93 

94 2. Derive SpW phase offsets while using SpW combination for the high-frequency ``'offset'`` solve only. 

95 

96 >>> hifa_diffgaincal(hm_spwmapmode='offset') 

97 

98 """

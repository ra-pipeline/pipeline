13 """Detect spectral line features and subtract the baseline from calibrated single-dish spectra. 

14 

15 Generates baseline fitting tables and subtracts the baseline from the spectra by masking 

16 detected emission/absorption line regions. The WebLog shows three sections of spectral grid 

17 maps per source: 

18 

19 1. Spectra **before** baseline subtraction (red fitted curve overlaid on each grid cell). 

20 2. **Averaged** spectra per grid cell (improves S/N to reveal line features). 

21 3. Spectra **after** baseline subtraction (red line at zero level per grid cell). 

22 

23 Cyan-shaded regions indicate the sum of all emission-line channels identified across the 

24 entire map (not just the individual grid cell). A spatially integrated spectrum per ASDM, 

25 antenna, spw, and polarization is shown above each grid, with the magenta curve indicating 

26 atmospheric transmission and thick red bars marking channels excluded by the 

27 ``deviation mask`` algorithm. 

28 Representative spectra in each cell correspond to the valid pointing nearest the mean 

29 coordinates of all pointings in that grid cell. 

30 

31 .. figure:: /figures/hsd_baseline_representative.png 

32 :width: 60% 

33 :alt: Representative position determination 

34 

35 Examples of how representative positions are determined. Blue points are all 

36 pointings; brown crosses are the averaged coordinates; green circles mark the 

37 representative positions (nearest valid pointing to the averaged coordinates). 

38 

39 .. figure:: /figures/guide-img036.jpg 

40 :width: 60% 

41 :alt: hsd_baseline WebLog page 

42 

43 Example of the :func:`~pipeline.hsd.cli.hsd_baseline` WebLog page showing the first three spectral 

44 grid rows (before subtraction, averaged, after subtraction) for one spw. 

45 

46 Detailed per-antenna spectral maps can be accessed from the detail pages by clicking the 

47 **Spectral Window** link on each summary page. Filters by antenna, field, spectral window, 

48 and polarization are available in the upper part of the detail pages. 

49 

50 **Fitting order determination**: The default function is a cubic spline. The number of 

51 spline segments (``N_segment``) is determined via FFT analysis of the power spectrum of 

52 grouped spectra: 

53 

54 1. ``1 < P_FFT < 3`` -- ``N_segment = 4`` 

55 2. ``3 <= P_FFT < 5`` -- ``N_segment = 5`` 

56 3. ``5 <= P_FFT < 10`` -- ``N_segment = 6`` 

57 4. ``P_FFT >= 10`` -- ``N_segment = F_FFT * 2 + 2`` 

58 

59 The final ``N_segment`` is scaled by ``(Nch - N_mask) / Nch`` to account for masked channels. 

60 Specifying a non-negative integer for ``fitorder`` disables auto-determination. 

61 

62 **Mask range determination**: Emission/absorption channels are identified by comparing 

63 spectral deviation from the median against an MAD-based threshold. Up to 10 iterations 

64 are performed to detect weak lines; each detected range is extended while the intensity is 

65 monotonically decreasing/increasing. Binned spectra (widths 1, 4, 16, 64 for 4096-channel 

66 spws) are also analyzed for broad features, with threshold ``3.5 + sqrt(binning_width) * MAD``. 

67 

68 **Baseline flatness evaluation** (fourth section of the WebLog page): Emission-free channels 

69 are divided into 10 or 20 bins. ``MAX(mean) - MIN(mean)`` across bins is compared to the 

70 spectral rms ``sigma``. 

71 

72 .. figure:: /figures/guide-image-new-baselineflatness.png 

73 :width: 60% 

74 :alt: Baseline flatness evaluation 

75 

76 Example of baseline flatness evaluation. 

77 

78 **Clustering analysis** for spectral line detection (developer plots, hidden by default; 

79 enable with ``plotlevel='all'`` in ``h_init``): 

80 

81 *Detection*: grid cells with emission exceeding the threshold are identified. Yellow cells 

82 have a single time-domain group with detected emission; cyan cells have more than one. 

83 

84 .. figure:: /figures/guide-img037.png 

85 :width: 60% 

86 :alt: Clustering detection 

87 

88 Clustering detection step. 

89 

90 *Validation*: for each grid cell the ratio of spectra containing detected emission lines 

91 (``Nmember``) to total spectra in the cell (``Nspectra``) is computed: 

92 

93 - **Validated** if ``Nmember/Nspectra > 0.5`` 

94 - **Marginally validated** if ``Nmember/Nspectra > 0.3`` 

95 - **Questionable** if ``Nmember/Nspectra > 0.2`` 

96 

97 .. figure:: /figures/guide-img038.png 

98 :width: 60% 

99 :alt: Clustering validation 

100 

101 Clustering validation step. 

102 

103 *Smoothing*: the per-cell ratio is convolved with a Gaussian-like grid function to suppress 

104 isolated single-line candidates and reinforce detections supported by neighboring cells. 

105 

106 .. figure:: /figures/guide-img039.png 

107 :width: 60% 

108 :alt: Clustering smoothing 

109 

110 Clustering smoothing step. 

111 

112 *Mask region determination*: in the validated area after smoothing, mask channel ranges are 

113 computed over the spatial domain by inter/extrapolating the mask ranges of the averaged 

114 spectra in validated cells and applied to each individual spectrum. 

115 

116 .. figure:: /figures/guide-img040.png 

117 :width: 60% 

118 :alt: Mask range calculation 

119 

120 Mask range calculation — in blue squares the mask 

121 range is interpolated from validated cells. 

122 

123 .. figure:: /figures/guide-img041.png 

124 :width: 60% 

125 :alt: Clustering final 

126 

127 Clustering final example. 

128 

129 Notes: 

130 Three QA scores are computed: 

131 

132 **Spectral line detection**: 

133 

134 - QA = 1.0 if no edge-line and main line is narrow. 

135 - QA = 0.60 if no edge-line and main line is wide. 

136 - QA = 0.55 if edge-line detected (regardless of main line width). 

137 - QA = 0.80 if no spectral lines are detected. 

138 - QA = 0.88 if the deviation mask overlaps with spectral or atmospheric lines. 

139 

140 **Baseline flatness** (MAX(mean) - MIN(mean) vs. sigma): 

141 

142 - QA = 0.33 if MAX(mean) - MIN(mean) > 3.6 sigma. 

143 - QA = 0.33-1.0 if 1.8 sigma <= MAX(mean) - MIN(mean) < 3.6 sigma. 

144 - QA = 1.0 if MAX(mean) - MIN(mean) < 1.8 sigma. 

145 

146 **Deviation from zero-baseline**: QA = 0.65 if significant deviation outside candidate 

147 line ranges is detected (triggering deviation masks). 

148 

149 Warning: 

150 :func:`~pipeline.hsd.cli.hsd_baseline` overwrites results from previous runs. If processing spws separately, 

151 each spw must be taken through to the imaging stage before the next spw is processed:: 

152 

153 hsd_baseline(spw='0'); hsd_blflag(spw='0'); hsd_imaging(spw='0') 

154 hsd_baseline(spw='1'); hsd_blflag(spw='1'); hsd_imaging(spw='1') 

155 

156 Examples: 

157 1. Basic usage with automatic line detection: 

158 

159 >>> hsd_baseline(antenna='PM03', spw='17,19') 

160 

161 2. Use pre-defined line windows instead of automatic detection: 

162 

163 >>> hsd_baseline(linewindow=[[100, 200], [1200, 1400]], linewindowmode='replace', edge=[10, 10]) 

164 

165 3. Per-spw pre-defined line windows merged with automatic detection: 

166 

167 >>> hsd_baseline(linewindow={19: [[390, 550]], 23: [[100, 200], [1200, 1400]]}, 

168 ... linewindowmode='merge') 

169 

170 """

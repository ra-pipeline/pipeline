8 """Restore flagged and calibration single dish data from a pipeline run. 

9 

10 The hsdn_restoredata task restores flagged and calibrated data from archived 

11 MeasurementSets (MSes) and pipeline flagging and calibration data products. 

12 

13 hsdn_restoredata assumes that the MSes to be restored are present in the 

14 directory specified by the ``rawdata_dir`` (default: '../rawdata'). 

15 

16 By default (``copytoraw`` = True), hsdn_restoredata assumes that for each 

17 MS in the input list, the corresponding pipeline flagging and calibration 

18 data products (in the format produced by the hsdn_exportdata task) are 

19 present in the directory specified by ``products_dir`` (default: '../products'). 

20 At the start of the task, these products are copied from the ``products_dir`` 

21 to the ``rawdata_dir``. 

22 

23 If ``copytoraw`` = False, hsdn_restoredata assumes that these products are 

24 to be found in ``rawdata_dir`` along with the MSes. 

25 

26 The expected flagging and calibration products (for each MS) include: 

27 

28 - a compressed tar file of the final flagversions file, e.g. 

29 uid___A002_X30a93d_X43e.ms.flagversions.tar.gz 

30 

31 - a text file containing the applycal instructions, e.g. 

32 uid___A002_X30a93d_X43e.ms.calapply.txt 

33 

34 - a compressed tar file containing the caltables for the parent session, 

35 e.g. uid___A001_X74_X29.session_3.caltables.tar.gz 

36 

37 

38 hsdn_restoredata performs the following operations: 

39 

40 - imports the MS(s) 

41 - removes the default MS.flagversions directory created by the filler 

42 - restores the final MS.flagversions directory stored by the pipeline 

43 - restores the final set of pipeline flags to the MS 

44 - restores the final calibration state of the MS 

45 - restores the final calibration tables for each MS 

46 - applies the calibration tables to each MS 

47 

48 When importing the MS, if the output MS already exists in the output directory, 

49 the existing MS will be imported instead. 

50 

51 Examples: 

52 1. Restore the pipeline results for a single MS in a single session 

53 

54 >>> hsdn_restoredata (vis=['mg2-20181016165248-190320.ms'], reffile='nroscalefactor.csv') 

55 

56 """

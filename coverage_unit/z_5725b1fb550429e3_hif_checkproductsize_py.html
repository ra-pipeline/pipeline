8 """Mitigate imaging product sizes to fit within specified thresholds. 

9 

10 This task modifies the characteristics of the imaging products in order to decrease their size,  

11 thereby decreasing the time needed to make them so that data can be delivered to PIs more expediently,  

12 and to prevent ``tclean`` failures on excessively large cubes. Datasets that have been mitigated will  

13 have imaging products with different characteristics than those that have not been mitigated.  

14 

15 The pipeline recipe explicitly encodes the threshold values so they can be easily changed universally  

16 for all pipeline runs. The ``casa_pipescript.py`` also encodes these values explicitly, so they can  

17 be modified on a per-MOUS basis. Full imaging products can be recreated by users without mitigation  

18 by modifying the ``tclean`` commands in the ``casa_commands.log`` file. 

19 

20 **Size Calculations**: 

21  

22 The size calculations (in GB) are based on the following: 

23 

24 - ``mfssize = 4.0 * nx * ny / 1e9`` 

25 - ``cubesize = 4.0 * nx * ny * nchan / nbin / 1e9`` 

26 - ``productsize = 2.0 * (mfssize + cubesize)`` 

27 

28 The 4 is the number of bytes per pixel, and the 2.0 accounts for the intensity image and the primary  

29 beam image, which are both delivered to the user. When a full polarization IQUV imaging recipe is used,  

30 this is inflated by a factor of 5 to account for the 4 axes in the IQUV image in addition to the initial  

31 Stokes I image. 

32 

33 **Mitigation Cascade**: 

34 

35 The mitigations are done in a priority order, halting once the predicted sizes fall below the thresholds.  

36 The default limits are ``maxcubesize=40 GB``, ``maxcubelimit=60 GB``, and ``maxproductsize=500 GB``. 

37 

38 - **Step 1** (If ``cubesize > maxcubesize``, for each spw exceeding the limit): 

39 

40 a. Channel binning: set ``nbin=2`` if nchan == 3840 or in (1920, 960, 480) without prior 

41 online channel averaging. 

42 b. Primary beam (PB) level reduction: calculate the PB response level at which the largest cube size  

43 equals the max allowed. The formula used is ``PB_mitigation = exp(ln(0.2) * maxcubesize / current_cubesize)``. 

44 This is adjusted for padding (``* 1.02``), capped at PB=0.7, and rounded to 2 significant digits.  

45 NOTE: this mitigation only applies to single fields (not mosaics) and uses the same mitigated FoV for all targets. 

46 c. Cell size reduction: change pixels-per-beam from 5 to 3.25 (if ``robust=+2``) or 3.0 (otherwise). 

47 d. If still too large: stop with an error because the largest size cube(s) cannot be mitigated. 

48 

49 - **Step 2** (If ``productsize > maxproductsize``): 

50 

51 a. If the number of science targets (single fields or mosaics) is greater than 1, reduce the number of targets  

52 to be imaged until productsize < maxproductsize. The representative target is always retained. 

53 b. If still too large, repeat steps 1a, 1b, and 1c, recalculating productsize each time. 

54 c. If still too large: stop with an error because the productsize cannot be mitigated. 

55 

56 - **Step 3** (Limit large cubes): 

57 

58 a. If there are cubes with sizes > 0.5 * maxcubelimit, limit the number of large cubes to be cleaned to 1.  

59 The spw encompassing the representative frequency is always retained. 

60 

61 - **Step 4** (Limit many science targets): 

62 

63 a. For projects with many science targets, limit the number to be imaged to 30. The representative target  

64 is always retained. 

65 

66 .. figure:: /figures/guide-img028.png 

67 :alt: Check product size mitigation example 

68 

69 Screenshot of the hif_checkproductsize stage. In this example, the spws had to be binned by a factor of 2  

70 and a single field selected in order to get the products below the thresholds.  

71 

72 Notes: 

73 QA = 1.0 if no mitigation was necessary; 0.85 (blue) if mitigation was applied; 0.0 if an error was encountered. 

74 

75 When the cube or product size cannot be mitigated, the warning "QA Maximum cube size cannot be mitigated"  

76 will appear at the top of the hif_checkproductsize stage, and the pipeline will stop in the first  

77 :func:`~pipeline.hif.cli.hif_makeimlist` (cube) stage with the message: "Error! Size mitigation had failed.  

78 Will not create any clean targets." 

79 

80 Examples: 

81 1. Check product sizes with internal defaults: 

82 

83 >>> hif_checkproductsize() 

84 

85 2. Standard ALMA call with explicit thresholds: 

86 

87 >>> hif_checkproductsize(maxcubesize=40.0, maxcubelimit=60.0, maxproductsize=350.0) 

88 

89 """

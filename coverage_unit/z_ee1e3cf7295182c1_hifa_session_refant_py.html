6def hifa_session_refant(vis=None, phase_threshold=None): 

7 """Select a single common reference antenna per session for polarization observations. 

8 

9 Re-evaluates the reference antenna lists from all MeasurementSets within a session and selects a single 

10 common reference antenna per session to be used by all subsequent pipeline stages. 

11 

12 The selection algorithm: 

13 

14 1. Rank all antennas by the product of their per-EB rankings (based on flagging fraction and central 

15 location in the array, as in :func:`~pipeline.hif.cli.hif_refant`). 

16 2. Starting from the highest-ranked antenna, perform a ``gaincal`` with ``solint='int'``, ``calmode='p'``, 

17 ``gaintype='G'``, ``minsnr=3`` on all PHASE intent scans for each EB. 

18 3. Check the resulting caltable to see if the reference antenna ever changes. Choose the first antenna for 

19 which no refant changes occur. 

20 4. If none of the top-3 candidates qualify (which should be rare), choose the antenna with the most 

21 solutions as refant and display the number of phase-solution outliers (integrations where the refant 

22 phase was non-zero, meaning another refant was used). The total number of possible solutions is 

23 N_EBs x N_spws x N_integrations x N_pol. 

24 

25 If a single refant was requested via :func:`~pipeline.hif.cli.hif_refant` in the PPR, a warning is generated indicating that 

26 only one antenna is common across all MSes. 

27 

28 Notes: 

29 QA = 1.0 if a suitable session reference antenna is found, otherwise 0.0. 

30 

31 Only used in polarization recipes. 

32 

33 Examples: 

34 1. Compute a single common reference antenna per session: 

35 

36 >>> hifa_session_refant() 

37 

38 """

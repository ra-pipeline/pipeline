127 vis: List of input visibility files. 

128 Default: ``None``, in which case the vis files to be used 

129 will be read from the context. 

130 

131 Example: ``vis=['ngc5921.ms']`` 

132 

133 caltable: List of output gain calibration tables. 

134 Default: none, in which case the names of the caltables 

135 will be generated automatically. 

136 

137 Example: ``caltable='ngc5921.wvr'`` 

138 

139 offsetstable: List of input temperature offsets table files to subtract 

140 from WVR measurements before calculating phase corrections. 

141 Default: none, in which case no offsets are applied. 

142 

143 Example: ``offsetstable=['ngc5921.cloud_offsets']`` 

144 

145 hm_toffset: If 'manual', set the ``toffset`` parameter to the user-specified value. 

146 If 'automatic', set the ``toffset`` parameter according to the 

147 date of the MeasurementSet; ``toffset=-1`` if before 2013-01-21T00:00:00 

148 ``toffset=0`` otherwise. 

149 

150 toffset: Time offset (sec) between interferometric and WVR data. 

151 

152 segsource: If True calculate new atmospheric phase correction coefficients 

153 for each source, subject to the constraints of the ``tie`` parameter. 

154 'segsource' is forced to be True if the ``tie`` parameter is set to a 

155 non-empty value by the user or by the automatic heuristic. 

156 

157 hm_tie: If 'manual', set the ``tie`` parameter to the 

158 user-specified value. If 'automatic', set the ``tie`` 

159 parameter to include with the target all calibrators 

160 that are within 15 degrees of it: if no calibrators are 

161 that close then ``tie`` is left empty. 

162 

163 tie: Use the same atmospheric phase correction coefficients 

164 when calculating the WVR correction for all sources in 

165 the ``tie``. If ``tie`` is not empty then ``segsource`` 

166 is forced to be True. Ignored unless ``hm_tie`` = 'manual'. 

167 

168 Example: ``tie=['3C273,NGC253', 'IC433,3C279']`` 

169 

170 sourceflag: Flag the WVR data for these source(s) as bad and do not 

171 produce corrections for it. Requires ``segsource`` = True. 

172 

173 Example: ``['3C273']`` 

174 

175 nsol: Number of solutions for phase correction coefficients during this 

176 observation, evenly distributed in time throughout the observation. It 

177 is used only if ``segsource`` = False because if ``segsource`` = True then the 

178 coefficients are recomputed whenever the telescope moves to a new 

179 source (within the limits imposed by ``tie``). 

180 

181 disperse: Apply correction for dispersion. (Deprecated; will be removed) 

182 

183 wvrflag: Flag the WVR data for the listed antennas as bad and replace 

184 their data with values interpolated from the 3 nearest antennas with 

185 unflagged data. 

186 

187 Example: ``['DV03','DA05','PM02']`` 

188 

189 hm_smooth: If 'manual' set the ``smooth`` parameter to the user-specified value. 

190 If 'automatic', run the wvrgcal task with the range of ``smooth`` parameters 

191 required to match the integration time of the wvr data to that of the 

192 interferometric data in each spectral window. 

193 

194 smooth: Smooth WVR data on this timescale before calculating the correction. 

195 Ignored unless hm_smooth='manual'. 

196 

197 scale: Scale the entire phase correction by this factor. 

198 

199 maxdistm: Maximum distance in meters of an antenna used for interpolation 

200 from a flagged antenna. 

201 Default: -1 (automatically set to 100m if >50% of 

202 antennas are 7m antennas without WVR and otherwise set to 

203 500m). 

204 

205 Example: ``maxdistm=550`` 

206 

207 minnumants: Minimum number of nearby antennas (up to 3) used for 

208 interpolation from a flagged antenna. 

209 

210 Example: ``minnumants=3`` 

211 

212 mingoodfrac: Minimum fraction of good data per antenna. 

213 

214 refant: Ranked comma delimited list of reference antennas. 

215 

216 Example: ``refant='DV01,DV02'`` 

217 

218 qa_intent: The list of data intents on which the wvr correction is to be 

219 tried as a means of estimating its effectiveness. 

220 A QA 'view' will be calculated for each specified intent, in each spectral 

221 window in each vis file. 

222 Each QA 'view' will consist of a pair of 2-d images with dimensions 

223 ['ANTENNA', 'TIME'], one showing the data phase-noise before the 

224 wvr application, the second showing the phase noise after (both 'before' 

225 and 'after' images have a bandpass calibration applied as well). 

226 An overall QA score is calculated for each vis file, by dividing the 

227 'before' images by the 'after' and taking the median of the result. An 

228 overall score of 1 would correspond to no change in the phase noise, 

229 a score > 1 implies an improvement. 

230 If the overall score for a vis file is less than the value in 

231 'accept_threshold' then the wvr calibration file is not made available 

232 for merging into the context for use in the subsequent reduction. 

233 If you do not want any QA calculations then set qa_intent=''. 

234 

235 Example: ``qa_intent='PHASE'`` 

236 

237 qa_bandpass_intent: The data intent to use for the bandpass calibration in 

238 the qa calculation. The default is blank to allow the underlying bandpass 

239 task to select a sensible intent if the dataset lacks BANDPASS data. 

240 

241 qa_spw: The SpW(s) to use for the qa calculation, in the order that they 

242 should be tried. Input as a comma-separated list. The default is blank, in 

243 which case the task will try SpWs in order of decreasing median sky 

244 opacity. 

245 

246 qa_combine: Used to set whether the spws can be combined. 

247 The trigger to combine SpW in the phase based gaincal when lowSNR 

248 data are present. This parameter is reported back from the pre-bandpass  

249 phaseup lowSNR assessment. Default is no combine, i.e. = ''  

250 

251 qa_solint: The solution interval in the phase based gaincal when lowSNR 

252 data are present. This parameter is reported back from the pre-bandpass  

253 phaseup lowSNR assessment. Default is 'int' 

254 

255 accept_threshold: The phase-rms improvement ratio 

256 (rms without wvr / rms with wvr) above which the wrvg file will be 

257 accepted into the context for subsequent application. 

258 

259 bandpass_result: 

260 

261 nowvr_result: 

262

476 def analyse(self, result): 

477 inputs = self.inputs 

478 

479 # check that the caltable was actually generated 

480 on_disk = [ca for ca in result.pool if ca.exists()] 

481 missing = [ca for ca in result.pool if ca not in on_disk] 

482 result.error.clear() 

483 result.error.update(missing) 

484 

485 # wvrcal files to be applied 

486 result.final[:] = on_disk 

487 

488 # If no QA intent was provided, then return early. Otherwise, continue 

489 # with computing the QA results. 

490 qa_intent = inputs.qa_intent.strip() 

491 if not qa_intent: 

492 return result 

493 

494 # Return early if no WVR caltable was created. 

495 if not result.final: 

496 return result

498 # Determine the list of SpWs for which QA results are needed. If no QA 

499 # SpW order was specified explicitly, then calculate an order here based 

500 # on SpW bandwidth and Tsys; otherwise use the specified order. 

501 # PIPE-3006 if in the second loop after any antenna flags reestablish spwlist again 

502 if inputs.qa_spw == '' or inputs.qa_combine == 'spw': 

503 # PIPE-2056: if the observing mode is band-to-band, then restrict 

504 # the list of QA SpWs to only the diffgain on-source SpWs, otherwise 

505 # use all science SpWs. 

506 if inputs.ms.is_band_to_band: 

507 spws = inputs.ms.get_spectral_windows(intent='DIFFGAINSRC') 

508 else: 

509 spws = inputs.ms.get_spectral_windows(science_windows_only=True) 

510 

511 # Initialize atmosphere heuristics. 

512 atmheuristics = atm_heuristic.AtmHeuristics(context=inputs.context, vis=inputs.vis, spw=spws) 

513 

514 # Create a ranked list preferably by Tsys and SpW bandwidth. 

515 qa_spw_list = atmheuristics.spwid_rank_by_tsys_and_bandwidth(qa_intent) 

516 

517 # If ranking by Tsys failed (e.g. no Tsys table, or due to 

518 # flagging), then fall back to ranking by opacity and bandwidth: 

519 if qa_spw_list is None: 

520 LOG.info(f"qa: ranking spws by bandwidth and Tsys failed for {inputs.ms.basename}; will rank by" 

521 f" bandwidth and opacity instead.") 

522 qa_spw_list = atmheuristics.spwid_rank_by_opacity_and_bandwidth() 

523 else: 

524 qa_spw_list = inputs.qa_spw.split(',') 

525 

526 # PIPE-3006 get string of all spws required and pass to the bandpass to run lowSNR heuristics  

527 # for a spectral scan we want to avoid passing all spws as this will take unnecessary time 

528 # to solve the bandpass. Thus, loop the spws per spectral spec and use those spws of the spectral spec 

529 # matching the top ranked qa_spw_list spw. 

530 spspec_to_spwid = utils.get_spectralspec_to_spwid_map(inputs.ms.get_spectral_windows(','.join(sorted(qa_spw_list)))) 

531 for spwids in spspec_to_spwid.values(): 

532 if int(qa_spw_list[0]) in spwids: 

533 qa_spw_list = [qa_spw for qa_spw in qa_spw_list if int(qa_spw) in spwids] 

534 LOG.info(f'filtered spw rank: {qa_spw_list}')

541 else:

544 # combine and solint are passed as hidden inputs the same as qa_spw which was already coded 

545 inputs.qa_combine, inputs.qa_solint = self._check_for_combine(bp_result) 

546

548 # that we know any subsequent gaincal will also need combine as not to 

549 # fail or drop lots of solutions.

551 LOG.info(f'lowSNR data for {inputs.ms.basename}, combining spectral windows to calculate wvrgcal QA') 

552 inputs.qa_spw = ','.join(sorted(qa_spw_list))

565 def phasediff_matcher(calto: callibrary.CalToArgs, calfrom: callibrary.CalFrom) -> bool: 

566 calto_vis = {os.path.basename(v) for v in calto.vis} 

567 return 'solintinf.gpcal.nowvr' in calfrom.gaintable and inputs.ms.basename in calto_vis 

568 

569 LOG.info('Unregistering previous phasediff without wvr calibration while task executes') 

570 inputs.context.callibrary.unregister_calibrations(phasediff_matcher) 

571 

572 LOG.info(f'qa: wvrgcal QA calculation was successful') 

573 LOG.info(f' will pass solutions in combined SpW {sorted(qa_spw_list)[0]} for with/without WVR assessment') 

574 else: 

575 # result of no-wvr gaincal is passed through 

576 nowvr_result = self._do_nowvr_gaincal(inputs) 

577 LOG.info(f'qa: wvrgcal QA calculation without WVR is reused') 

578 LOG.info(f' will pass solutions in combined SpW {sorted(qa_spw_list)[0]} for with/without WVR assessment') 

579 

580 

581 # set the single result qa spw as the minimum spw of the qa_spw_list 

582 result.qa_wvr.qa_spw = sorted(qa_spw_list)[0] 

583 

584 

585 else: 

586 # If no combine='spw' loop over the qa_spw_list as ordered 

587 # in a second loop this qa_spw_list is "the" QA spw 

588 for qa_spw in qa_spw_list: 

589 LOG.info(f'qa: {inputs.ms.basename} attempting to calculate wvrgcal QA using spw {qa_spw}') 

590 inputs.qa_spw = qa_spw 

591 nowvr_result = self._do_nowvr_gaincal(inputs) 

592 if not nowvr_result.final: 

593 continue 

594 else: 

595 LOG.info('qa: wvrgcal QA calculation was successful') 

596 LOG.info(f' will pass solutions in SpW {qa_spw} for with/without WVR assessment') 

597 result.qa_wvr.qa_spw = qa_spw 

598 break 

599 

600 # PIPE-3006 Need to be set as in subsequent loops (after flags) these are cached and reused 

601 result.qa_wvr.qa_combine = inputs.qa_combine 

602 result.qa_wvr.qa_solint = inputs.qa_solint 

603 

604 # note full result saving out of the loop  

605 inputs.bandpass_result = bp_result 

606 inputs.nowvr_result = nowvr_result 

607 result.qa_wvr.bandpass_result = bp_result 

608 result.qa_wvr.nowvr_result = nowvr_result 

609 

610 

611 # Accept the result object into the local copy of the context, thus 

612 # adding the WVR table to the callibrary of this local copy. 

613 # PIPE-1058: accepting the result requires a stage number. Normally, 

614 # this would be added by the task execution infrastructure. In this 

615 # the result of the currently-still-running task is being accepted 

616 # into a local context already, before the result has been finalised, 

617 # so need to explicitly set stage number now. 

618 LOG.debug('qa: accept WVR results into copy of context') 

619 result.stage_number = inputs.context.task_counter 

620 result.accept(inputs.context) 

621 

622 # do a phase calibration on the bandpass and phase calibrators, now 

623 # with bandpas *and* wvr preapplied. 

624 if not bp_result.final: 

625 LOG.warning('qa: calculating phase calibration with wvr applied') 

626 else: 

627 LOG.info('qa: calculating phase calibration with bandpass and wvr applied') 

628 

629 # PIPE-3006 now with the WVR solution we have to process combine or not 

630 # this should always run even if a second loop after antenna flagging 

631 if inputs.qa_combine =='spw': 

632 # A phasediff is required to offset all 

633 # SpW before doing the no wvr gaincal with combine='spw' 

634 # result needs to be in local context 

635 wvr_phasediff_result = self._do_phasediff_gaincal(inputs, True) 

636 wvr_phasediff_result.accept(inputs.context) 

637 wvr_result = self._do_wvr_gaincal(inputs) 

638 # must now remove the gaintable from the local context as the 

639 # phasediff is not valid for further solves 

640 

641 def phasediff_matcher(calto: callibrary.CalToArgs, calfrom: callibrary.CalFrom) -> bool: 

642 calto_vis = {os.path.basename(v) for v in calto.vis} 

643 return 'solintinf.gpcal.wvr' in calfrom.gaintable and inputs.ms.basename in calto_vis 

644 

645 LOG.info('Unregistering previous phasediff with wvr calibration while task executes') 

646 inputs.context.callibrary.unregister_calibrations(phasediff_matcher) 

647 else: 

648 wvr_result = self._do_wvr_gaincal(inputs) 

649 

650 # finally save both with and without WVR result caltables  

651 nowvr_caltable = nowvr_result.inputs['caltable'] 

652 wvr_caltable = wvr_result.inputs['caltable'] 

653 result.qa_wvr.gaintable_wvr = wvr_caltable 

654 

655 # Edited for PIPE-1837 adding BPgood and PHgood 

656 LOG.info('qa: calculate ratio with-WVR phase RMS / without-WVR phase rms') 

657 result.PHnoisy, result.BPnoisy, result.PHgood, result.BPgood = wvrg_qa.calculate_view(inputs.context, nowvr_caltable, wvr_caltable, 

658 result.qa_wvr, qa_intent) 

659 

660 result.suggest_remcloud = wvrg_qa.calculate_qa_numbers(result.qa_wvr, result.wvr_infos, result.PHnoisy, result.BPnoisy) 

661 

662 # PIPE-846: report improvement factors. 

663 self._report_wvr_improvement(result) 

664 

665 # if the qa score indicates that applying the wvrg file will 

666 # make things worse then remove it from the results so that 

667 # it cannot be accepted into the context. 

668 if result.qa_wvr.overall_score < inputs.accept_threshold: 

669 LOG.warning('wvrgcal has qa score (%s) below accept_threshold ' 

670 '(%s) and will not be applied' % 

671 (result.qa_wvr.overall_score, inputs.accept_threshold)) 

672 result.final[:] = [] 

673 

674 return result

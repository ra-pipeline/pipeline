8 """Set calibrator source models. 

9 

10 The model flux density of the amplitude calibrator is set, either from an internal CASA model (solar system 

11 objects), or from the results of observatory calibrator monitoring (quasars) which ultimately appear in the file 

12 ``flux.csv`` (see :func:`~pipeline.hifa.cli.hifa_importdata`). These flux densities are listed on the WebLog page, along with plots of 

13 the amplitude calibrator as a function of uv distance (which is useful to assess resolved solar system objects). 

14 If the bandpass calibrator is distinct from the amplitude calibrator and is a frequently monitored quasar, its 

15 model is also set at this stage. 

16 

17 Set model fluxes values for calibrator reference and transfer sources using lookup values. By default the 

18 reference sources are the flux calibrators and the transfer sources are the bandpass, phase, and check source 

19 calibrators. Reference sources which are also in the transfer source list are removed from the transfer source 

20 list. 

21 

22 Built-in lookup tables are used to compute models for solar system object calibrators. Point source models are 

23 used for other calibrators with flux densities provided in the reference file. Normalized fluxes are computed for 

24 transfer sources if the ``normfluxes`` parameter is set to True. 

25 

26 The default reference file is ``flux.csv`` in the current working directory. This file is usually created in the 

27 importdata stage. The file is in CSV format and contains the following comma-delimited columns:: 

28 

29 vis, fieldid, spwid, I, Q, U, V, pix, comment 

30 

31 Notes: 

32 **QA Scoring** 

33 

34 The QA score is set to 1.0 if the flux density of the amplitude calibrator is successfully set for all 

35 spectral windows and if the spectral index of the bandpass calibrator is set; otherwise it is set to 0.0. 

36 

37 Examples: 

38 1. Set model fluxes for the flux, bandpass, phase, and check sources. 

39 

40 >>> hif_setmodels()

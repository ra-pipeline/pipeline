15 """Flag deviant system temperatures in the Tsys calibration table. 

16 

17 Flags erroneous Tsys measurements in the calibration table created by :func:`~pipeline.h.cli.h_tsyscal`. Detected anomalies include 

18 anomalously high Tsys over an entire spectral window, spikes or 'birdies', and discrepant spectral shape as a 

19 function of frequency. The WebLog provides details for each kind of flagging performed and plots all Tsys 

20 spectra after flagging. If a Tsys flag template file is provided via the ``filetemplate`` parameter, those 

21 manual flags are also applied. 

22 

23 Six separate flagging metrics are evaluated in the order set by ``metric_order`` 

24 (default: ``'nmedian, derivative, edgechans, fieldshape, birdies, toomany'``): 

25 

26 **1. nmedian** — Flag time/antenna points with anomalously high median Tsys. 

27 A time x antenna matrix view is built per polarisation and spw. Points are flagged if their value exceeds 

28 ``fnm_limit`` (default: 2.0) times the median of all non-flagged data points. Individual sources are evaluated 

29 separately when ``fnm_byfield=True`` (default) to prevent elevation differences from causing spurious flags at 

30 high frequencies. 

31 

32 **2. derivative** — Flag time/antenna points with high median channel-to-channel derivative (ringing). 

33 For each antenna/timestamp the view value is calculated as 

34 ``median(abs(valid_data - median(valid_data))) * 100.0``, where ``valid_data`` is the channel-to-channel 

35 difference of Tsys normalized by the frequency median of Tsys. Points are flagged if their absolute value 

36 exceeds ``fd_max_limit`` (default: 5). 

37 

38 **3. edgechans** — Flag edge channels of the Tsys spectra. 

39 A median Tsys spectrum (over all antennas) is formed per spw per intent (ATMOSPHERE, BANDPASS, AMPLITUDE). 

40 Edge channels are flagged from the outermost inward until the first channel where the channel-to-channel 

41 difference falls below ``fe_edge_limit`` (default: 3.0) times the median channel-to-channel difference. 

42 

43 **4. fieldshape** — Flag time/antenna points whose Tsys spectral shape differs from the reference. 

44 The view value is ``100 * mean(abs(normalized_Tsys - reference_normalized_Tsys))`` where the reference 

45 is formed from the ``ff_refintent`` (default: ``'BANDPASS'``) intent fields. Points are flagged if their 

46 value exceeds ``ff_max_limit`` (default: 13). 

47 

48 **5. birdies** — Flag narrow spikes that appear in some but not all antennas. 

49 A difference spectrum (per-antenna median minus all-antenna median) is formed per spw/antenna. The 

50 'sharps' rule runs two passes: 

51 

52 1. Flag channels whose absolute step to the next channel exceeds ``fb_sharps_limit`` (default: 0.15). 

53 2. Around each newly flagged channel, flag neighbours until the channel-to-channel difference drops below 

54 twice the median channel-to-channel difference. 

55 

56 **6. toomany** — Flag entire timestamps or spws when too many antennas are already flagged. 

57 Uses the same time x antenna matrix as 'nmedian'. Two sub-rules are applied: 

58 

59 - ``tmf`` (too many flags): Flag an entire timestamp if the fraction of flagged antennas exceeds 

60 ``tmf1_limit`` (default: 0.666). 

61 - ``tmef`` (too many entirely flagged): Flag all antennas in all timestamps within a (spw, pol) view if 

62 the fraction of entirely flagged antennas exceeds ``tmef1_limit`` (default: 0.666). 

63 

64 Notes: 

65 QA = 0.0 if additional flagging fraction >= 50%, QA = 1.0 if <= 5%, linearly interpolated between 0 and 1 

66 for fractions between 5% and 50%. An additional score of 0.8 is assigned if any spw has an antenna that is 

67 fully flagged. 

68 

69 Examples: 

70 1. Flag Tsys measurements using currently recommended tests: 

71 

72 >>> hifa_tsysflag() 

73 

74 2. Flag Tsys measurements using all recommended tests apart from the 'fieldshape' metric: 

75 

76 >>> hifa_tsysflag(flag_fieldshape=False) 

77 

78 """
